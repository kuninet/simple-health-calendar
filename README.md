# Simple Health Calendar 🩺

排便・血圧・体重などの体調を記録するシンプルなカレンダーアプリです。
[simple-exercise-calendar](https://github.com/kuninet/simple-exercise-calendar) の姉妹アプリで、
「達成を褒める」エクササイズカレンダーに対して、こちらは「体調を観察する」ための記録アプリです。

## ✨ 特徴

- **7種類の体調記録**: 排便・血圧・体重・体温・睡眠・服薬・体調メモ
- **1日に何回でも記録**: 時刻つきで記録できる（排便や血圧の朝晩測定に対応）
- **カレンダーにアイコン表示**: 何を記録した日か、ひと目でわかる
- **日別詳細**: 日付をタップするとその日の記録一覧と追加フォーム
- **グラフ表示**: 体重・血圧・体温・睡眠の推移を折れ線グラフで確認
- **複数ユーザー対応**: 画面上はユーザーごとに記録を分離（切り替え式。認証はありません → [セキュリティについて](#-セキュリティについて)）
- **📱 PWA対応**: iPhone・Androidのホーム画面に追加してアプリのように使える

## 📋 記録できる項目

| 種別 | アイコン | 記録内容 |
|------|---------|---------|
| 排便 | 💩 | 状態（ブリストルスケール タイプ1〜7）、量 |
| 血圧 | ❤️ | 上（収縮期）・下（拡張期）・脈拍 |
| 体重 | ⚖️ | 体重(kg)・体脂肪率(%) |
| 体温 | 🌡️ | 体温(℃) |
| 睡眠 | 😴 | 睡眠時間 |
| 服薬 | 💊 | 薬の名前 |
| 体調メモ | 📝 | 自由メモ（頭痛・不調など何でも） |

すべての記録に時刻とメモを付けられます。

## 🚀 クイックスタート

### 必要な環境

- Node.js 20.17.0 以上

### インストールと起動

```bash
npm install
npm run gen-icons   # PWA用のPNGアイコンを生成（初回のみ）
npm start
```

ブラウザで http://localhost:3100 を開いてください。

エクササイズカレンダー（ポート3000）と同じマシンで同居できるよう、
デフォルトポートは **3100** にしています。変更する場合:

```bash
PORT=8080 npm start
```

## 🔌 API

| メソッド | パス | 説明 |
|---------|------|------|
| GET | `/api/users` | ユーザー一覧 |
| POST | `/api/users` | ユーザー追加 |
| GET | `/api/records?user_id&year&month` | 月の記録一覧 |
| GET | `/api/records/day?user_id&date` | 1日の記録 |
| POST | `/api/records` | 記録追加 |
| PUT | `/api/records/:id` | 記録更新 |
| DELETE | `/api/records/:id` | 記録削除 |
| GET | `/api/series?user_id&type&days` | グラフ用時系列 |
| GET | `/api/export?user_id` | JSONエクスポート |

## 🗄️ データ

- SQLite（`health-app.db`）に保存されます
- 記録はユーザーID・種別・日付・時刻と、種別ごとの計測値(JSON)で保持します
- `/api/export` でJSONとしてバックアップできます

## 🔒 セキュリティについて

本アプリは**家庭内LANでの利用を想定しており、認証機能はありません**。
アクセスできる人は誰でも全ユーザーの記録を閲覧・編集できます。
体調記録はプライベートな情報です。インターネットに直接公開せず、
自宅のネットワーク内、または VPN・リバースプロキシの認証の内側で利用してください。

## ⚠️ 免責

本アプリは個人の生活記録用であり、医療機器ではありません。
体調に不安がある場合は医療機関を受診してください。
